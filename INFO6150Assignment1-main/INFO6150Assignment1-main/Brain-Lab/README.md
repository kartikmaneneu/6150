A website based on Neuroscience exploring the functions of your mind and interesting facts.

## Technologies Used

- HTML5
- CSS

## HTML Tags Used

- `<html>` - Defines the whole HTML document.
- `<head>` - Contains Info about the links and resources of the page.
- `<meta>` - Defines the character encoding of the page.
- `<title>` - Tag which displays the title on the browser tab.
- `<link>` - Connect the page to external style sheets or script files.
- `<body>` - Tag which have the visible content of page.
- `<header>` - Contains the main icon and navigation links of the website.
- `<nav>` - Tag which have the particular navigation links of the page.
- `<div>` - Container element which organizes the contents.
- `<span>` - Container element just like the div tag but used to organise a smaller peice of code.
- `<img>` - Tag which I used to display images.
- `<br>` - Tag which I used to add a line break.
- `<section>` - Groups related content together.
- `<p>` - Used to display text as a paragraph or a line generally.
- `<h1>` - Defines the main heading of our page.
- `<h2>` - Defines a secondary section heading.
- `<h3>` - Defines a smaller heading within a section.
- `<h5>` - Defines a smaller heading used for the card descriptions.
- `<button>` - Creates a button.
- `<a>` - It is a anchor element which creates a hyperlink which can be used to navigate.
- `<aside>` - Contains additional info related to the main content.
- `<article>` - Used to represent featured article.
- `<audio> <video>` - I've used these tags to render the audio/video.
- `<source>` - defines a path from where that particular audio/video is getting used.
- `<table> <thead> <tbody> <tr> <th> <td>` - I used it to create a table with heading, body, cells. 
- `<form> <label> <input>` - These are the tags which I've used to create a form with inout fields and added labels too.
- `<datalist> <options>` - I've used this to give users suggested topics using options tag.
- `<ul> <li>` - Used it to make an unordered list with, "li" tag being individual item.
- `<footer>` - Used this tag to organize the bottom most section of the page where contact and copyright info lies.
- `<strong>` - Used this tag to important text.
- `<small>` - Displays smaller supporting text.
